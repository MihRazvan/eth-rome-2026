# Integrated browser acceptance

`npm run test:browser` runs five independent Chromium scenarios against actual deployed local contracts; no network mocking or hidden UI fixture is used. Chain31337 is explicitly labelled. Test data begins with funded testUSDC and immutable test vault contracts. Each mutating scenario creates its own claim through visible actions.

0. Idle-time maturity originates a backed claim and waits for its first installment without any test-clock RPC, servicing transaction, injected response or manual refresh. Automatic one-second mixed mining advances the chain and the visible Collect4,000 action becomes enabled.
1. Public seller payment9960 is checked against independent token balances and owner/epoch. The browser then requests a full-value quote, collects and withdraws4000, observes it stale, creates/accepts a5985 residual offer, collects/withdraws6000 and independently checks final ownership, cash0 and withdrawn10000. Anvil time advances only for this **local test**; source timestamps are not altered on Fuji.
2. A custom private9987.123456 quote is encrypted in the maker browser. Captured upload body and independently retrieved records contain no quote price or netPayment field. The seller reads exact6-decimal terms after reload; a fresh outsider browser sees ciphertext-only offers. Settlement then pays exactly9987.123456 and the public Accepted event discloses that amount.
3. Markets are inspected after the chain-backed rows load at390/1024/1440 widths, including no document overflow.
4. Onchain device-key rotation increments version, revocation clears the active hash, and old held keys can still decrypt historical offers. A separately authored quote is cancelled onchain and appears cancelled to the seller. Key revocation is never represented as quote cancellation.

Screenshots are under browser-integrated/. Independent evaluation (different agent, manually operated browser and independent chain reads) is recorded in browser-independent.md. Its findings were corrected: completed standard payout labels, net-cost wording, encrypted identity labels and mobile sponsor-status text. Portfolio distinguishes current viewer's collected cash from previous owners' withdrawals. Known transaction confirmation survives a failed refresh; cancelled or altered replacements never masquerade as completed settlement.

Initial automated failures included exact-text selectors not accounting for count badges, expecting3 makers when the seller was one maker (correct2 eligible), a test assertion racing a pending withdrawal, and an implicit label selector. These were corrected to assert actual visible semantics and receipt-complete state. Browser/runtime findings included deadline seconds/milliseconds, duplicate cash partitioning and unfunded refreshed maker allowances. Product fixes were applied before passing acceptance.

Baseline fresh-process run: all four original tests passed in14.5s, with the test runner starting and stopping the entire local stack itself. The final idle-maturity regression increases the suite to five tests, all passing in1.2m. Earlier responsive captures were taken before loading; the test now requires the local environment and visible claim rows, and the committed captures were replaced with the verified loaded state. A prior overlapping rerun also caused a trace-file collision; the final fresh-process run completed serially.

Hosted visual preview: https://exit-ethrome-2026.vercel.app/?preview=1 returned HTTP200, rendered the explicit illustrative-data label and had zero browser page errors. The default URL visibly reports unavailable live services and offers the preview/local-run links; no fixture fallback. `hosted-preview.png` is separate from local transaction evidence.

Limitations: no injected-wallet Fuji signing was exercised because funded accounts were unavailable. No real Swarm publication/Arkiv mutation is represented by local byte/index records. Concept preview checks remain explicitly separate. Native browser plugin's required tool was absent, so Playwright was used and actually executed.
