# Cutout assets

The Cutout visual direction comes from the six HTML studies supplied by the project owner on 12 September 2026. The artwork here is a new vector implementation of their paper, perforation, silhouette and envelope motifs. Decorative artwork contains no claim about a user's credential or task state.

Typography is self-hosted so loading the app does not contact Google Fonts. Downloaded 12 September 2026 from the Google Fonts source repository:

- `archivo-variable.ttf`: https://github.com/google/fonts/blob/main/ofl/archivo/Archivo%5Bwdth,wght%5D.ttf — Archivo by Omnibus-Type. Original license: `archivo-OFL.txt`.
- `ibm-plex-mono-regular.ttf`: https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf — IBM Plex Mono. Original license: `ibm-plex-mono-OFL.txt`.

Both fonts use the SIL Open Font License 1.1; they are unmodified. Use Archivo for headings and interface copy; IBM Plex Mono for metadata, references and small labels.

The orange brand color is `#F04E23`. Small button text uses dark ink for contrast. Large orange headings use `#B93413` on the paper surface, preserving the color direction with readable contrast.

## Deaddrop typography — 13 September 2026

The Deaddrop app skin follows the owner's `deaddrop-app-v2.html` reference: Martian Mono display type, Azeret Mono controls and metadata, and the existing Archivo variable font for prose. Fonts are self-hosted; the app makes no Google Fonts runtime requests. Earlier Cutout assets and their licenses remain for provenance.

These unmodified variable fonts were downloaded from the official Google Fonts source repository:

- `martian-mono-variable.ttf`: [Martian Mono](https://github.com/google/fonts/blob/main/ofl/martianmono/MartianMono%5Bwdth%2Cwght%5D.ttf), by Evil Martians. Original SIL Open Font License 1.1: `martian-mono-OFL.txt`.
- `azeret-mono-variable.ttf`: [Azeret Mono](https://github.com/google/fonts/blob/main/ofl/azeretmono/AzeretMono%5Bwght%5D.ttf), by the Azeret Fonts Project Authors. Original SIL Open Font License 1.1: `azeret-mono-OFL.txt`.

The Deaddrop palette uses void `#060404`, ember `#FF5A1F`, bone `#FFF3E2`, cold `#5C9FF5` and ice `#7FD9FF`. Orange marks actions; blue marks verified progress and private report controls. Decorative styling does not manufacture an eligibility, delivery or payment result.
