What this experiment proves

One local machine simulates issuer, reviewer, client and arbitrator with separate test files. The Groth16 proof is genuine; proving runs in a local Go helper, not in the browser. Browser document encryption sends only ciphertext to local Bee nodes. The demonstration retains the decryption key in this tab; cross-device key sharing is not implemented.

Qualification gates admission. The client judges the review. Timely submission is paid after a three-hour review deadline unless disputed; a trusted test arbitrator resolves disputes. Later revocation does not cancel earned payment.
